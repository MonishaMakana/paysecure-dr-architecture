Runbook 09: API Gateway Incident Mitigation

Scope

This runbook covers API Gateway and edge endpoint outages affecting merchant traffic.

Objective

  • Restore API availability quickly
  • Maintain payment acceptance and merchant connectivity

Preconditions

  • API Gateway endpoints exist in both Mumbai and Hyderabad.
  • Route 53 failover health checks monitor API availability.
  • API keys and mTLS certificates are up to date.

Immediate Actions

  1. Confirm API Gateway endpoints are unavailable.
  2. Check Route 53 health check results and API Gateway logs.
  3. Fail over to the healthy region by switching DNS weights.

RTO Steps

  1. Validate merchant traffic reaches the alternate region.
  2. Confirm API Gateway stage deployment and authorization settings.
  3. If certificate issues exist, rotate certificates and redeploy.

Validation

  • Perform end-to-end payment request tests.
  • Confirm API responses and latency.
  • Validate merchant authentication and authorization success.

Post-Recovery Activities

  • Review API Gateway configuration and stage deployment processes.
  • Update DNS and certificate automation as needed.
  • Report the incident to stakeholders.
